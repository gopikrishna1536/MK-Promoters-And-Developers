# MK Promoters and Developers

Responsive real estate company website starter for Visakhapatnam, built with React, Vite, React Router, Lucide icons and Supabase.

Start with `npm install`, then `cp .env.example .env`, and `npm run dev`. Full setup instructions are in [SETUP.md](./SETUP.md). Run `supabase-schema.sql` in the Supabase SQL editor to create the tables and starter Row Level Security policies.
